# Telegram Bot для подписки на прокси через Marzban с интеграцией API

🤖 Полнофункциональный Telegram бот для управления подписками на прокси-серверы через панель Marzban с интегрированной системой оплаты через ЮКасса.

## 🔄 Архитектура с Marzban API

Бот использует **гибридную архитектуру**:
- **База данных пользователей**: Marzban API (основной источник)
- **Локальная БД**: Связи Telegram ↔ Marzban + история платежей
- **Синхронизация**: Данные всегда актуальны из Marzban

## 🚀 Функции

- 🔐 **Управление подписками** через Marzban API
- 💳 **Оплата через ЮКасса** (встроенные платежи Telegram)  
- 📊 **Просмотр информации о тарифе** из Marzban в реальном времени
- 🌍 **Выбор региона сервера**
- 🔑 **Генерация QR-кодов** для подключения
- ⏰ **Отслеживание истечения подписки** в реальном времени
- 👨‍💼 **Админ-панель** с данными из Marzban
- 🔄 **Автоматическая синхронизация** с Marzban

## 📦 Установка

### 1. Клонирование проекта
```bash
git clone <repository_url>
cd marzban_telegram_bot
```

### 2. Создание виртуального окружения
```bash
python -m venv venv

# Linux/Mac
source venv/bin/activate

# Windows  
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка окружения
```bash
cp .env.example .env
```

Отредактируйте файл `.env` и заполните настройки:

```env
# Telegram Bot Token (получить у @BotFather)
BOT_TOKEN=your_bot_token_here

# YooKassa (ЮКасса) настройки
YOOKASSA_SHOP_ID=your_shop_id
YOOKASSA_SECRET_KEY=your_secret_key
YOOKASSA_PROVIDER_TOKEN=your_provider_token

# Marzban API настройки
MARZBAN_API_URL=https://your-marzban-panel.com
MARZBAN_USERNAME=admin
MARZBAN_PASSWORD=your_password

# Админы (ID получить у @userinfobot)
ADMIN_IDS=123456789,987654321
```

### 5. Запуск бота
```bash
python main.py
```

## 🔧 Настройка компонентов

### Telegram Bot
1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен и добавьте в `.env`
3. Настройте команды:
   ```
   start - Запуск бота и главное меню
   help - Справка по использованию
   subscription - Информация о подписке
   admin - Административная панель
   stats - Быстрая статистика
   ```

### ЮКасса (YooKassa)
1. Зарегистрируйтесь в [ЮКасса](https://yookassa.ru/)
2. Получите `shop_id` и `secret_key` в личном кабинете
3. Настройте провайдер платежей в [@BotFather](https://t.me/BotFather):
   - Выберите вашего бота
   - Payments → Connect Payment Provider
   - Выберите YooKassa
   - Введите данные из ЮКасса

### Marzban Panel
1. Установите и настройте [Marzban панель](https://github.com/Gozargah/Marzban)
2. Создайте админ пользователя
3. **Важно**: Включите API в настройках:
   ```bash
   # В .env файле Marzban
   DOCS=True
   ```
4. Добавьте API credentials в `.env` бота
5. Убедитесь что Marzban доступен по HTTPS

## 🔌 Интеграция с Marzban

### API Endpoints используемые ботом:
- `POST /api/admin/token` - Авторизация
- `GET /api/users` - Список всех пользователей
- `GET /api/user/{username}` - Информация о пользователе
- `POST /api/user` - Создание пользователя
- `PUT /api/user/{username}` - Изменение пользователя
- `DELETE /api/user/{username}` - Удаление пользователя
- `GET /api/user/{username}/usage` - Статистика использования
- `GET /api/system` - Системная статистика
- `GET /sub/{username}` - Subscription URL

### Источники данных:
- **Пользователи**: Marzban API (`/api/users`)
- **Статистика трафика**: Marzban API (`/api/user/{username}/usage`) 
- **Подписки**: Marzban API (`/sub/{username}`)
- **Системная статистика**: Marzban API (`/api/system`)

### Локальная БД хранит:
- Связи `telegram_id ↔ marzban_username`
- История платежей ЮКасса
- Настройки бота

- `/admin` - Административная панель (только для админов)
- `/stats` - Быстрая статистика (только для админов)

### Для пользователей:
1. **Покупка подписки**:
   - Выбор региона сервера
   - Выбор тарифного плана

   - Автоматическое создание в Marzban

2. **Управление подпиской**:
   - Просмотр статуса и трафика (из Marzban)
   - Получение ключей подключения
   - Генерация QR-кодов
   - Отслеживание срока действия

### Для администраторов:
1. **Мониторинг пользователей** из Marzban с реальными статусами
2. **Статистика использования** из Marzban API
3. **История платежей** из локальной БД

## 🔧 Алгоритм работы

### Процесс покупки:
1. Пользователь выбирает регион и план
2. Создается пользователь в Marzban через API
3. Генерируется платежная ссылка ЮКасса
4. После оплаты подписка сразу активна
5. Пользователь получает ключи и QR-код

### Просмотр подписки:
1. По `telegram_id` находится `marzban_username`
2. Запрос к Marzban API за актуальными данными
3. Отображение реальной статистики трафика
4. Конвертация timestamp в читаемые даты

### Административная панель:
1. Получение всех пользователей из Marzban
2. Агрегация статистики трафика
3. Объединение с локальными платежами
4. Формирование сводных отчетов

## 🛠️ Технические особенности

### Архитектурные решения:
- **API-first подход**: данные из Marzban API
- **Гибридное хранение**: критичные связи локально
- **Асинхронность**: все операции неблокирующие
- **Кэширование токенов**: эффективная работа с API
- **Graceful degradation**: обработка недоступности API

### Стек технологий:
- **aiogram 3.21.0** - современный фреймворк для Telegram ботов
- **aiohttp** - асинхронный HTTP клиент для Marzban API
- **yookassa** - официальная библиотека ЮКасса
- **qrcode** - генерация QR-кодов
- **aiosqlite** - асинхронная работа с SQLite
- **python-dotenv** - управление переменными окружения

## 🔍 Отладка

```bash
curl -X POST "https://your-marzban-panel.com/api/admin/token" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"your_password"}'
```

### Проверка логов:
```bash
tail -f bot.log
```

### Типичные ошибки:
1. **401 Unauthorized** - неверные данные Marzban
2. **Connection refused** - Marzban недоступен
3. **Payment failed** - проблемы с ЮКасса
